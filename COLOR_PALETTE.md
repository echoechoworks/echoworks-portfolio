# Farveskema — tape machine

Farveskemaet er udledt af Abbey Road J37-referencen: patineret metal, tape-emalje, varme jordtoner og få tydelige signaler.

| Navn | Hex | Anvendelse |
| --- | --- | --- |
| Kulsort | `#171917` | Navigation, metadatafelter og dybe kontraster |
| Mørk umber | `#362523` | Rammer, kanter og små bokse |
| Blågrøn emalje | `#364D4F` | Metadata-labels og små kontroller |
| Støvet grågrøn | `#84918A` | Projektkort og sekundære flader |
| Lys salvie | `#C4C5B3` | Lys tekst og bløde kontraster |
| Varm sand | `#D1C3A9` | Tekstflader, detaljer og indramninger |
| Oxidrød | `#B4574B` | Aktive knapper og markeringer |
| Signal-gul | `#DBCB26` | Links, små statusdetaljer og handlinger |
| Metalgrå | `#777A70` | Diskrete skillelinjer og sekundær tekst |

## Principper

- Lad mørk umber, sort og de grønne toner danne strukturen.
- Brug sand og lys salvie til læsbarhed og varme.
- Brug oxidrød og signal-gul sparsomt: de skal altid pege på en handling, status eller et aktivt valg.
- Hold siden materiel og rolig frem for teknologisk eller steril.
